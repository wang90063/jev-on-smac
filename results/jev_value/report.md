# Jev 当价值模型：离线测试

日期 2026-10-01。数据来自 val 上带真值的决策点（第十轮生成，见 `results/search/rollout_val.json`），从中随机抽 300 个点。每个点问 Jev 一次，同时问 14 个二选一问题（"现在赢不赢"，以及 13 个"执行某个动作后赢不赢"），读取它给出的胜率。调用 300 次，0 次失败。

| 项目 | Jev | 对照 |
|---|---:|---:|
| 判断局势：P(赢) 与真实胜负的 AUC | 0.787 | 只看双方血量比：0.835 |
| 判断动作：按它选动作实际拿到的收益（上限 37.5） | -6.3 ~ -1.1（τ 0~0.2） | 现有价值模型 +1.1 |
| 和真实优势的排序相关性 | 0.054 | 现有价值模型 0.305 |
| 13 个动作的胜率差异（标准差） | 0.047 | – |
| 作为现有模型的附加特征 | 不稳定，有升有降 | – |

结论：Jev 不适合当价值模型。
- 它能大致判断局势，但不如单个血量比特征。
- 它对不同动作给出的胜率几乎一样，分不出哪个动作更好；按它选，收益为负。
- 把它的输出加到现有模型上，也没有稳定的增益。

## 加上下文学习：每次给 8 个最相似的训练时刻（附每个选项的真实结果）

示例的选择方式：在标准化后的物理特征上取最近的 8 个训练决策点（确定性检索，不让模型挑）。每个示例包含局面的物理摘要，以及 13 个选项各自真实打出的胜负。对照组是"把同样 8 个示例的结果直接求平均"。平均每次调用 6816 个输入 token，300 次调用，0 次失败。

**判断局势**（P(赢) 与真实胜负的 AUC）：

| | AUC |
|---|---:|
| Jev，不给示例 | 0.787 |
| **Jev + 8 个示例** | **0.857** |
| 只看血量比 | 0.835 |
| 8 个示例直接求平均 | 0.771 |

按场景分组做 bootstrap：
- Jev 加示例相对不加：+0.070，95% 置信区间 [+0.011, +0.135]，**显著**。
- Jev 加示例相对只看血量比：+0.022，95% 置信区间 [-0.052, +0.106]，不显著。

**判断动作**（上限 37.5）：

| | 最好的实际收益 | 排序相关性 |
|---|---:|---:|
| Jev，不给示例 | -1.1 | 0.05 |
| Jev + 8 个示例 | +0.1 | 0.17 |
| **8 个示例直接求平均** | **+5.4** | 0.28 |
| 现有价值模型 | +1.1 | 0.31 |

结论：
- 上下文学习对 Jev **有效**。它判断"能不能赢"明显变准，成为所有方法里最好的，也比把同样示例直接求平均更好。但相对只看血量比的优势还不显著。
- 在"挑哪个动作"上，Jev 仍然不如把同样示例直接求平均。看来它能综合局面判断大势，但区分不了动作之间的细微差别。
- 一个顺带的发现：在这 300 个点上，"8 个近邻直接求平均"挑动作的效果（+5.4）好于现有价值模型（+1.1）。这只是一批样本上的离线结果，需要做在线对局验证后才能下结论。
