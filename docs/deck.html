实验设置 · 环境与数据

两类战斗：照着写规则的官方图，和谁都没看过的生成战斗

环境

  • SMAClite：Python 重写的 SMAC，不需要星际 2。
  • 1 步 ≈ 0.5 秒游戏时间，超时算输。
  • 游戏会等策略，所以延迟只花墙钟时间，不影响胜负。

结果 · 第 1 步

Jev 直接控制每个单位：35 局一局没赢，和随机合法动作一样

胜场 / 35 局（7 张官方图 × 5 个种子）
Jev 下限 随机 固定规则

3m（种子 1）：Jev 让三个机枪兵一起往东走（P = 0.95），然后把火力分散到三个敌人身上。敌人不分散，最后剩 2 个单位获胜。

三个可能的原因

  1. 动作空间大。每个单位每 0.5 秒有 6–17 个动作，一场仗要连续几十步都对。
  2. 题目之间不能协同。同一请求里的题目各自独立打分；而集火是"谁打谁"的联合分配。
  3. 动作的差别是数值。射程、冷却、距离决定胜负。300 个决策点上，Jev 对 13 个动作给出的胜率，标准差只有 0.047。

还慢：这个规模下每次请求 1.23 秒，比一步的 0.5 秒还长。

读法

  • 每组是一个实验：Jev 替系统做某个选择，和系统自己的选择逐局配对。
  • 有设置的实验都先在 val 上调，再在测试集上只跑一次。
  • 最好的一次是 +6，而示例投票是 +5。
  • ③ 没有独立测试集：在 Claude 程序自己的 720 局开发数据上，示例按场景留一法抽取。
为什么

挑战术的空间很小；空间在逐单位的执行里，而那正是 Jev 做不了的

对胜率的影响 · 百分点
挑选：事后最优的上限 执行：实际测得

挑选是上限（事后最好的选项），执行是实际测到的差值，所以这张图对挑选是偏宽的。

大多数战斗，选哪个都一样

  • 2,717 个决策点，每个把 13 个选项都打到底：只有 284 个（10%）存在能改变胜负的选项。
  • 第 20 步从"等"切到"压"：720 局里只有 43 局结果变了（25 赢、18 输）。
  • 所有战术选项底下跑的是同一套执行代码：谁打谁、什么时候后撤。挑哪个都碰不到它。

唯一的长处：判断"能不能赢"

每个决策点问"从这里能赢吗"，附 8 个最相似的历史时刻。AUC 条从 0.5（瞎猜）画起。Jev 最好，但不显著。而且微操里没有能用上这个判断的动作：不能撤退、增援、投降。

Jev 可能适合的地方

少量、高代价、能用文字描述的决策，而且判断能变成动作：撤退、增援、这仗不打。全局宏观运营符合这些条件；小规模微操正好相反。

外部结果（JEV-Star，实时星际 2 宏观）：Jev 单独 0 / 10；在 LLM 计划过滤后的动作里挑，9 / 10。

Take away · 方法

下次用判断模型之前

01

先量上限

在一部分种子上为每个场景挑最好的选项，再到别的种子上验证。如果只值几个百分点，谁来挑都无所谓。这里"等还是压"的上限只有 3.5%。

02

永远对照"同样信息、没有模型"

四种对照：随机挑、示例投票、手写规则、系统默认。Jev 在每一步都被其中一个追平。

03

小提升要换种子确认

一个改动在挑选种子上 +7，换了种子变成 −14（p = 0.049）。小于 +15 的提升，一定要在没参与挑选的种子上再测。

04

别信调参用过的地图

手写规则和 Jev 的题目都照着官方图写：在那里 92 和 91，到了新战斗就和 SMAC：focus 打平。泛化只看没见过的战斗。

附录 B · 价值切换怎么训练

离线复制模拟器打标签，再用 DAgger 补上模型自己走到的局面

1 · 走到决策点驱动策略（最近簇的程序）正常打，每 5 步停一次
2 · 复制模拟器 仅离线13 个选项各执行 5 步，再交回驱动策略打到底
3 · 打标签Q = 赢(1/0) + 0.1 ×（我方剩余血量比 − 敌方剩余血量比）
4 · 学优势y = Q(选项) − Q(默认)，梯度提升树回归
5 · 在线使用每 5 步算特征；预测优势最大且 > τ = 0.1 才换，否则保持默认
↺6 · DAgger把第 5 步的价值策略当成新的驱动策略，回到第 1 步：在它自己走到的局面上再打一轮标签，和旧数据合并重训。只用最近簇程序驱动，模型只见过"好好打"时的局面；一旦自己换了战术，就走到没见过的地方。train、train2 各做一轮。

数据：约 1.1 万个决策点 × 13 个选项 ≈ 14 万次回放

def in_range(u, e, slack=0.3):
    # can_attack 只说明"看得见"；射程要自己算
    return can_attack(u, e) and dist(u, e) <= u.range + u.radius + e.radius + slack

def threat(e, A):                          # 敌人每秒能打掉我们多少血
    …                                              # 医疗艇、自爆兵另算
    cd = e.max_cooldown if e.max_cooldown > 0 else 1.0
    return e.damage * e.attacks / cd

# 集火分配：这一步能开火、且射程内有目标的单位
ready = [u for u in A if u.cooldown < READY and u.id not in out]
